# Simple Coding Agent

## Overview
The Simple Coding Agent is a tool designed to assist with coding tasks, including analyzing repository structures, generating documentation, and executing various coding-related operations.

## Installation
To install the Simple Coding Agent, follow these steps:


1. Navigate to the project directory:
   ```bash
   cd simple-coding-agent
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
The Simple Coding Agent can be used in both interactive and automated modes. Below are some common usage scenarios:

### Interactive Mode
To run the agent in interactive mode, simply execute:
```bash
python simple_coding_agent.py
```

### Automated Mode
To run automated tests, use the following command:
```bash
python test_simple_coding_agent_leetcode.py
```
